📢 Advertising

When you are approved by an ad network, paste your client id and slot ids into assets/js/data.js (PN_ADS). Placeholders become real ads automatically – no other change needed.

🎮 Where to get more free & modern games (legally)

  • GameDistribution and GameMonetize – publisher programmes with thousands of HTML5 games; you copy an embed code and (optionally) share ad revenue.
  • itch.io – many creators allow embedding; check each game’s page and licence.
  • GitHub open-source games – check the licence (MIT / CC0 are easiest), host them in games/ and credit the author.

Then click ＋ Add game and paste the embed code in the Quick add box. Only add games you have permission to use.
